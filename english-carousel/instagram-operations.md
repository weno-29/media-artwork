# CDP Instagram運用計画｜英語カルーセル

著者名：上野ニッカ ／ 出版社名：Connecting Dots Publishing（CDP）
元資料：英語カルーセル投稿企画 議事録（2026-10-06）
開始予定：2026年10月7日以降

> 注：数値目標・投稿頻度は「提案値」です。Instagramの仕様やアルゴリズムは変わるため、運用開始時に公式ヘルプで最新仕様を確認し、数週間のデータで調整します。

---

## 1. 運用の目的

- 最終目的：CDPの認知を広げ、コンテンツ（note、ショート動画、書籍）への導線をつくる。
- 手段：「同じフォーマット × 毎回違う英語知識」のカルーセルを反復投稿する。
- TikTokと素材を共通化し、媒体ごとの作り直しはしない。

## 2. アカウント設計

| 項目 | 方針 |
|---|---|
| アカウント | CDP公式Instagram |
| 言語 | 画像内は英語中心（海外ユーザーにも通じる設計）。キャプションは英語を先頭、日本語を補助にする案 |
| プロフィール文 | 一目でわかる1行（例：Everyday English, naturally. / 古い英語と教養英語も） |
| プロフィールリンク | CDPの受け皿ページ（note等）。リンク先は運用開始前に確定 |
| ハイライト | 「Beginner→Natural」「Rare English」の2本に整理 |

## 3. 投稿フォーマット（固定）

> 色・フォント・ラベル位置は、CDP書籍カルーセルと共通の `../cdp-carousel/design-system.md` に従う（アカウント全体の統一感のため）。

- サイズ：縦長4:5（1080×1350px）を基準にする。
- 枚数：6〜7枚を基本とする。

| 枚 | 内容 |
|---|---|
| 1 | フック（例：Stop saying "VERY". Try these instead.） |
| 2〜5 | 本編。Beginner / Natural を左右比較、1枚5〜6例（議事録どおり） |
| 最終 | Learn more English with Connecting Dots Publishing（売り込みではなく「学べる場所」として提示） |

- 色・フォント・レイアウトは固定し、変えるのは英語の中身だけにする。
- 1枚目はスマホのグリッド表示でも読める大きさのタイトルにする。
- CEFRレベル（A1→C1等）の断定表記は使わない。「native」ではなく「Natural」を使う（議事録の方針）。

## 4. シリーズ運用

### シリーズ① Beginner → Natural
- 例：I'm very tired. → I'm exhausted.
- 1投稿5〜6表現。テーマ切り口例：very を使わない／I don't know の言い換え／職場／旅行／感情／食事。
- 自然さの根拠として、辞書の語義・用例を確認してから投稿する。

### シリーズ② 古い・珍しい・教養系英語
- 古風な英語、慣用句、文学的表現、歴史的表現、語源、ニュアンス差など。
- **必須：投稿前に辞書・コーパスで用例を確認する。** 確認できなければ投稿しない。
- 語源は俗説が多い領域。「諸説あり」の場合はその旨を明記する。

### 比率（提案）
立ち上げ期は①を多めにして型を固め、②を週1本から入れる（①：②＝およそ2：1）。

## 5. 投稿スケジュール（提案）

- 頻度：週3本（①を2本、②を1本）。続けられる頻度を優先する。
- 初期2週間のイメージ

| 日 | シリーズ | テーマ案 |
|---|---|---|
| 10/7 | ① | Stop saying "VERY"（very tired / busy / hungry …） |
| 10/9 | ① | "I don't know" の言い換え |
| 10/11 | ② | 古風な英語（用例確認後に決定） |
| 10/14 | ① | Stop saying "GOOD" |
| 10/16 | ① | 職場で使う Natural English |
| 10/18 | ② | 語源ネタ（確認後に決定） |

※10/7の初回は準備期間が1日のため、1本目はすぐ作れる「VERY」ネタを推奨。

## 6. キャプション雛形

```
[1行目：フックの繰り返し／英語]
Save this for later 📌

[日本語の補足 1〜2行]

Learn more English with Connecting Dots Publishing
Link in bio.

#EnglishLearning #LearnEnglish #EnglishVocabulary #NaturalEnglish
```

- ハッシュタグは少数（目安3〜5個）の関連語に絞り、毎回の使い回しを避ける。
- 保存・シェアを促す一言を1つだけ入れる。

## 7. TikTokとの連携

- 同じカルーセル素材を使い、TikTok用にはBGM・サイズだけ調整する（作り直さない）。
- 投稿は同日または翌日。反応の良いテーマに印を付けておく。
- 反応の良かったテーマは、後日 note記事 → ショート動画 → CDPコンテンツへ展開する。

## 8. 計測（毎週1回振り返る）

| 指標 | 見る理由 |
|---|---|
| 保存数 | 教育系で「役に立つ」の指標になりやすい |
| シェア数 | 拡散の指標 |
| リーチ（フォロワー外の割合） | 新規に届いているか |
| プロフィールアクセス／リンクのクリック | CDPへの導線が機能しているか |
| フォロワー増減 | 全体の成長 |

- 最初の4週間は目標を決めず、基準値をとる。
- 振り返りでは「1枚目のフック別」「テーマ別」に反応を比べ、伸びた型を増やす。

## 9. 制作フロー（1本あたり）

1. テーマと表現を決める（Beginner/Naturalの組み合わせ）
2. 辞書・コーパスで用例と自然さを確認（②は特に必須）
3. テンプレートに流し込み、画像を作成
4. 誤字・綴り・文法チェック（英語は2回読む）
5. キャプションを作成、予約または投稿
6. TikTokへ展開、ネタ管理表に記録

## 10. 投稿前チェックリスト

- [ ] 英語表現は辞書・用例で確認済みか
- [ ] 「Natural」と言い切れない表現に、場面（カジュアル／ビジネス等）を添えたか
- [ ] CEFRレベルの断定表記が入っていないか
- [ ] 1枚目だけで内容が伝わるか
- [ ] 最終ページのCDP導線が売り込みになっていないか
- [ ] 他者の画像・文章・フォントのライセンス問題がないか

## 11. 未決事項（要確認）

- CDP Instagramのアカウント名・既存フォロワー数・現在の投稿
- プロフィールリンクの遷移先（note／書籍ページ等）
- 画像制作ツール（Canvaでテンプレート化する案）
- 週3本の頻度を実際に維持できるか（制作時間の見積もり）
- キャプションの言語（英語のみ／英日併記）

# CDP書籍カルーセル 企画書

著者名：上野ニッカ ／ 出版社名：Connecting Dots Publishing
アカウント：Instagram @connectingdot_office ／ 言語：日本語（英語カルーセルとは別企画）

## 1. 方針（元メモより）

1. CDP公式アカウントをおしゃれに発信する
2. カルーセルの最終ページに書籍情報を置く
3. 日本語で出す
4. 白＋1色で統一し、洗練された見た目にする（→ `design-system.md`）
5. 書籍の内容を要約し、質問・メモ・豆知識形式にする
6. 統一感のある投稿が最優先

## 2. 英語カルーセルとの関係

- 企画は別。ただし色・フォント・ラベル位置・最終ページの枠を共通化する。
- フィード上で「英語」「書籍」が交互に並んでも同じアカウントに見えること。
- 最終ページの導線の文言トーンも揃える（売り込まず「もっと知る場所」として示す）。

## 3. 投稿の型（固定）

| 枚 | 役割 | ラベル |
|---|---|---|
| 1 | 問いのフック（書名は出さない） | なし |
| 2 | 問いへの答え（数字・事実） | `Q.` / `A.` |
| 3 | 考え方のメモ | `MEMO` |
| 4〜5 | 意外な豆知識（出典つき） | `TRIVIA` |
| 6 | 反論・留意点、または次の問い | `NOTE` |
| 7 | 書籍情報 | — |

- 事実と著者の仮説・意見は区別して書く（「本書は〜と考える」）。
- 書中で出典が示されている数字のみを使う。投稿前に一次資料で再確認する。

## 4. 対象書籍

- Driveの書籍カタログ（2026年4月版）の他、本文が確認できた書籍から順に作る。
- 第1弾：『宗教は悪なのか？――神の死とAIの時代に、私たちは何を信じるのか』（本文確認済み）
- **除外：『声よどこにいる』**
- 技術士・公認会計士・法律系などの試験対策シリーズも、「一問一答」「用語メモ」型で展開できる（本文確認後に作成）。

## 5. 投稿ペース（提案）

- 週1〜2本。英語カルーセル（週3本案）と合わせて、曜日を固定する。
- 例：月・水・金＝英語、火または土＝書籍。

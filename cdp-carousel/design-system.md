# 共通デザイン規格｜CDP Instagram（@connectingdot_office）

英語カルーセルとCDP書籍カルーセルで**共通利用**する。企画は別だが、見た目は同じアカウントの投稿として並んだときに一つに見えることを最優先にする（統一感が運用の要）。

> 色コード・フォントは提案値。Canva等でテンプレート化する前に確定する。

## 1. 色（白＋1色の2色）

| 役割 | 色 | 備考 |
|---|---|---|
| 背景 | 白 `#FFFFFF` | 全スライド共通 |
| 文字・罫線・アクセント | ディープネイビー `#1B2A41`（案） | これ1色のみ。濃淡（透明度）で強弱をつける |

- 写真・イラスト・グラデーションは使わない。例外は書籍表紙画像のみ（最終ページ）。
- 英語カルーセルの「Beginner / Natural」の区別も、色ではなく**罫線・太さ・位置**で表す。

## 2. 文字

- 見出し：明朝系（例：Noto Serif JP）／英語はセリフ体（例：Noto Serif）。
- 本文・補足：ゴシック系（例：Noto Sans JP）。
- 1枚の文字量：見出し＋本文で日本語100字前後まで。スマホで読める大きさを優先。
- 太さは2段階まで（見出し＝太、本文＝標準）。

## 3. レイアウト（4:5 / 1080×1350px）

- 余白：四辺 96px 以上。
- 左上に小ラベル（例：`Q.` `MEMO` `TRIVIA` ／ 英語は `BEGINNER → NATURAL` `RARE ENGLISH`）。
- 右下にページ番号（`2/7`）、左下に `Connecting Dots Publishing`（小）。
- 1枚目：大見出し中心、他は何も置かない。
- 最終ページ：英語は「Learn more English with Connecting Dots Publishing」、書籍は書籍情報（下記）。どちらも同じ位置・同じ枠で作る。

## 4. 書籍カルーセルの最終ページ

```
Connecting Dots Publishing
書名（サブタイトル）
著者：上野ニッカ
[表紙画像]
Kindle版｜プロフィールのリンクから
```

- 価格・配信状況・URLは投稿前に必ず確認して記入する（本資料では未確認）。

## 5. 禁止事項

- 書籍『声よどこにいる』は**取り上げない**（要約・引用・宣伝・書名の言及すべて禁止）。
- 売り込み口調、「絶対」「必ず儲かる」等の断定、根拠不明の数字。
- 出典のない統計・引用。出典があるものは「出典：」を小さく入れる。
